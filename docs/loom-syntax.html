Loom Syntax Highlighter

Loom includes a lightweight syntax highlighter designed specifically for Codeblock cards. It automatically detects the language and applies colour‑coded highlighting in real time.

How it works

The highlighter processes source code in a single pass, splitting it into tokens (keywords, strings, numbers, operators, etc.) and wrapping each token in <span> elements with CSS classes. The result is rendered directly in the Codeblock card preview and the full‑screen viewer.

Language detection uses a heuristic: it scans for language‑specific keywords and patterns (e.g., def for Python, function/arrow syntax for JavaScript, HTML tags, CSS rule blocks). The language with the highest score wins.

Supported languages

Language File extensions / context
JavaScript (JS) .js, .mjs, .cjs
Python (PY) .py
HTML .html, .htm
CSS .css

For HTML and CSS, Loom uses dedicated tokenizers that understand tags, attributes, CSS selectors, properties, and values.

Token types & CSS classes

Each token type is assigned a CSS class that you can customise via the theme. The default mapping is:

Token CSS class
Comment syn-comment
String syn-string
Number syn-number
Boolean / null / undefined syn-boolean
Keyword syn-keyword
Built‑in function / object syn-builtin
Function name syn-function
Class name syn-class
Operator syn-operator
Regex literal (JS) syn-regex
HTML tag syn-tag
HTML attribute name syn-attr-name
HTML attribute value syn-attr-value

You can find these styles in the theme CSS file. They are applied automatically inside any pre code block that receives highlighted output.

Using LoomSyntax in Codeblocks

When you create a Codeblock card, the highlighter runs on the code you enter in the Inspector. The card body shows a preview with syntax colours. The language badge in the header (e.g., “JS · 42 lines”) reflects the auto‑detected language.

There is no manual language selector — the highlighter decides based on content. If you need a specific language, include enough characteristic syntax (e.g., a def for Python, an HTML doctype or tags, CSS rule blocks).

API (for developers)

The highlighter is exposed as window.LoomSyntax with these methods:

  • LoomSyntax.highlight(code, lang?) — returns HTML string with span‑wrapped tokens. If lang is omitted, auto‑detects.
  • LoomSyntax.detectLanguage(code) — returns "js", "py", "html", or "css".
  • LoomSyntax.LANGUAGES — object with language metadata (name, keywords, etc.).

This API is used internally by the Codeblock card renderer and can also be called from the browser console for testing.

💡

Want to change the colours? Override the syn-* classes in your custom theme. The default theme uses the app’s accent colour for keywords and a warm palette for strings and numbers.
