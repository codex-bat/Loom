Loom Markdown

Loom includes a built‑in Markdown renderer that works in text blocks, card titles, and the Notes field. When you switch to View Mode (or enable per‑card preview), the raw Markdown is converted into formatted HTML.

Where Markdown is used

  • Text blocks inside standard Frame cards — write your script, notes, or descriptions in Markdown.
  • Card titles — the title field renders as Markdown in View Mode / preview.
  • Inspector Notes — the Notes textarea also renders Markdown in preview.

Markdown is only visible when a card is in preview state (or when the whole board is in View Mode). In Edit Mode you see the raw source.

Advanced details

  • Line breaks: A single newline is preserved inside a paragraph (<br>). Two newlines create a new paragraph.
  • URL safety: Links are sanitised — only http:, https:, mailto:, and tel: protocols are allowed.
  • Code blocks: You can optionally specify a language after the opening backticks (e.g., ```python) — it adds a CSS class but does not apply syntax highlighting (that is only done in Codeblock cards).
  • Escaping: To display a literal asterisk or underscore, use a backslash: \*.

Activating the preview

Markdown rendering is activated automatically when you:

  • Switch the entire board to View Mode (dropdown in the top bar).
  • Click the eye icon on a specific card header to toggle per‑card preview.
  • Press Ctrl + Shift + P to toggle preview for all visible cards at once.

While editing, you always see the raw Markdown source. The preview is a rendering overlay that hides the source fields.

✍️

Write your scene notes, shot descriptions, or character dialogue in Markdown. When presenting or exporting, the content will look polished without any extra tools.

⚠️

Markdown previews are session‑only and reset when you reload. To make formatting permanent in exports, use View Mode when exporting to PNG or sharing the .json file.
