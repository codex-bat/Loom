Loom · Reference

Build visual stories,
frame by frame.

Loom is a browser-based storyboard canvas. Arrange scene frames freely in 2D space, link them with strings to show narrative flow, add text, images, code, video, and links to each scene, then export your board as a shareable image or editable project file.

No sign-up Saves locally JSON export PNG export Keyboard-first

Getting Started

Open index.html in any modern browser and you're ready. Nothing installs, nothing syncs — your board lives entirely in your browser's local storage.

Your first storyboard

1
Add a card
Click the New dropdown in the top bar and choose Frame, Codeblock or Video Clip. A card appears at the centre of the canvas — it’s your first scene card.
2
Name it
Click the card’s title field and type a name. The same field appears in the Inspector panel on the right.
3
Add content
For a Frame, use the toolbar to add Text, Image or Link blocks. For a Codeblock, write code in the Inspector. For a Video Clip, paste a YouTube/Vimeo URL or upload a local file.
4
Arrange and connect
Drag cards into position. Drag the pin icon ◎ from one card header to another to draw a narrative connection.
5
Export
Click Export → Project to save a .json you can reopen later, or Export → Storyboard for a flattened .png snapshot.
💾

Loom auto-saves to localStorage after every action, so closing and reopening the tab will restore your work — as long as you're using the same browser.

The Canvas

The canvas is an infinite 2D world. Your cards float in it at any position. Navigate with pan and zoom; the grid and world origin orb help you stay oriented.

Panning

  • Ctrl + Drag on any empty area of the canvas.
  • Middle-click drag anywhere on the canvas (including on cards).
💡

Ctrl + Drag on a card moves the card itself with snap-alignment, not the camera.

Zooming

Scroll the mouse wheel (or trackpad pinch) anywhere on the canvas to zoom in or out. The zoom level is shown as a percentage in the top-right corner of the top bar.

  • F — Zoom to fit all visible cards into view (hidden-group cards excluded).
  • 0 — Reset to 100 % centred on the world origin.
  • Zoom range: 15 % – 250 %.

World origin

The point (0, 0) in world space is marked by a subtle glowing orb. Snap alignment and X/Y inspector values are all measured relative to this origin.

Grid

The background shows a fine dot grid (32 px) with larger major marks (160 px).

Box selection (marquee)

Click and drag on any empty area of the canvas (without holding Ctrl) to draw a selection rectangle. Any card whose bounding box overlaps the rectangle will be selected when you release. Hold Shift while drawing to add to an existing selection.

Select all

Press Ctrl + A to instantly select all visible cards (hidden-group cards excluded).

Card Types

Loom offers three card types — each tailored to a specific kind of content. Pick the right one from the New dropdown in the top bar.

Standard Frame

The classic card. It holds a title, a colour tag, and a free‑form body where you can add Text, Image or Link blocks (see Content Blocks). Use it for scene descriptions, shots, user‑flow steps, or anything that needs mixed media.

Codeblock

A card designed for displaying and editing code snippets. It features:

  • Syntax‑highlighted preview inside the card body. Language is auto‑detected.
  • Full‑screen code viewer — click the expand button (⤢) to open a modal with a larger, focused view.
  • Code editing happens in the Inspector panel, where a dedicated textarea lets you write or paste code.
  • Frame styling (tag colour and frame‑line) is available via a small toggle button next to the title in the Inspector.

Note: Codeblocks use syntax highlighting powered by LoomSyntax. The language badge (e.g., “JS · 42 lines”) appears in the card header.

Video Clip

A card for embedding video content. It supports two sources:

  • YouTube / Vimeo URLs — pasted in the Inspector. Thumbnail is automatically pulled from the platform.
  • Local video files — upload from your device. The file is stored as a data URL inside your project. 5 MB size limit — an alert appears if the file is too large.

When a local video is uploaded, Loom automatically generates a cover‑art thumbnail from a mid‑point frame. Click the play overlay to watch inline, or click the expand button to open a modal player (YouTube / Vimeo will embed the platform’s player).

Frame styling (tag colour and frame‑line) is also available for Video Clips via the Inspector toggle.

⚠️

Large video files significantly increase the .json project size. Keep clips short and low‑resolution for portability.

Content Blocks

The standard Frame card can hold any number of content blocks — text, images, and links — in any order. Use the toolbar at the bottom of the frame to add blocks.

Text blocks

Click Aa · Text to add a plain contenteditable area. In View Mode (or when a frame’s preview is toggled on), text blocks render as Markdown.

✍️

Write your script or shot notes in Markdown inside text blocks, then switch to View Mode to see them rendered cleanly for presentation.

Image blocks

Click ▢ · Image to open your device’s file picker. The image is embedded as a Base64 data URL, so it travels with your project file without separate assets.

⚠️

Large images increase the .json file size. Resize before importing.

Link blocks

Click 🔗 · Link, paste or type a URL, and press Enter. If you paste a URL without a protocol, https:// is prepended automatically. Press Escape to cancel.

Reordering blocks

Hover over any block to reveal a drag grip (☰) on its right edge. Drag it above or below other blocks to reorder.

Deleting blocks

Hover over any block and click the × button that appears (undoable).

Connections

Connections are the threads that link cards in a parent → child relationship, rendered as golden bezier strings with brass‑tack endpoints. They form a tree hierarchy visible in the Frame List.

Drawing a connection

Hover over or select any card. A pin icon (◎) appears in the top‑right of the header. Drag from that pin to another card — release over the target to create the connection.

  • The string preview is amber while dragging freely.
  • It turns teal when hovering over a valid target.
  • It turns red when hovering over an invalid target.

Connection constraints

  • Each card can have at most one parent.
  • Cycles are prevented — you cannot connect a card to one of its own ancestors.
  • Duplicate connections between the same two cards are not allowed.

When a drag lands on an invalid target, Loom shows a toast explaining the rejection.

Group inheritance

When you draw a connection from a parent that belongs to a group, the child (and all its descendants) automatically inherit that group membership.

Cutting a connection

Click anywhere along the string thread to remove it. The thread highlights red when hovered to signal that clicking will cut it.

String layer (front / behind cards)

Right‑click any string thread to open the context menu:

  • Send behind frames — the string renders underneath all cards.
  • Bring in front of frames — the string renders above all cards (default).
  • Apply to all strings — applies the same layer choice to every visible connection on the board at once (hidden‑group connections are skipped).

Connections and hidden groups

Connections involving cards in a hidden group are not drawn on the canvas. They are preserved in the project data and reappear when the group is made visible again.

Frame List

The left panel’s Frames section lists every card in hierarchy order, organised into groups and root‑level cards. A + button in the section header creates new groups.

Navigation

Click any row to select the card and pan the canvas to centre it in view.

Hierarchy display

Child cards are indented beneath their parents with an arrow connector symbol (↳). Each level adds 12 px of left padding.

Colour dot and number

Each row shows a coloured dot matching the card’s tag colour and a zero‑padded number reflecting creation order.

Dragging cards between groups

Drag any card row and drop it onto a group header row to assign the card (and its entire descendant subtree) to that group. Drag a card row to the Frames section header to remove it from any group.

Deleting from the list

Hover a card row to reveal a × delete button on the right. Clicking it removes the card and all its connections — identical to pressing Delete with the card selected on the canvas.

Groups

Groups let you cluster related cards together in the Frame List. They support collapsing, hiding, optional visual border highlights, drag‑to‑reorder, and a right‑click context menu for quick actions.

Creating a group

Click the + button in the top‑right of the Frames section header. A new group row appears named “New Group” — click the name field to rename it.

Adding cards to a group

Drag any card row from the Frame List and drop it onto the target group row. The card and all of its connected descendants move into the group together. A toast confirms how many cards were moved.

💡

You cannot drag a card into a group it already belongs to — Loom will notify you with a toast instead.

Removing cards from a group

Drag any card row to the Frames section header (the area above all groups). The card and its descendants are unassigned from the group and returned to the ungrouped root level.

Collapsing and expanding

Click the chevron (▾) on the left of a group row to collapse or expand the group’s rows in the list. Cards remain fully visible on the canvas — collapsing is a list‑view convenience, not a hide operation.

Hiding and showing group cards

Click the eye icon button on the group row to hide all cards in that group. Hidden cards:

  • Are removed from the canvas entirely (they don’t receive clicks or participate in box‑selection).
  • Have their connection strings hidden as well.
  • Are excluded from Zoom to Fit and Ctrl + A select‑all.
  • Are excluded from the storyboard PNG export.
  • Remain collapsed in the Frame List with all interactive controls dimmed.

Click the eye icon again (it shows a slashed eye while hidden) to restore all cards in that group.

Border highlight

Click the dashed‑rectangle icon button on a group row to toggle a visual border around all cards in the group on the canvas. The border is a dashed SVG rect drawn behind the cards, using the group’s accent colour (or default teal). It updates live as cards move or resize.

Right‑click context menu

Right‑click any group row (while in Edit Mode and while the group is not hidden) to open a context menu with:

  • Hide Frames / Show Frames
  • Show Borders / Hide Borders
  • Delete Group — removes the group and unassigns all its cards, without deleting the cards themselves.

Reordering groups

Hover a group row to reveal a grip handle (☰) on the left. Drag from the grip to reorder groups within the Frame List.

Deleting a group

Use the right‑click context menu and choose Delete Group. The group is removed and all its cards are unassigned (returned to the ungrouped pool) but not deleted from the canvas. This is undoable.

Inspector

The Inspector panel on the right shows editable metadata for the currently selected card. Selecting multiple cards locks the Inspector and shows a count badge instead.

Title

The card’s display name. Editable here or directly in the card header on the canvas — the two stay in sync. Maximum 60 characters. In View Mode (or with per‑card preview enabled), the title renders as Markdown.

Frame styling (collapsible)

A small arrow button next to the title opens a hidden block containing:

  • Tag color — six preset swatches that tint the border, glow, frame‑line stripe, and pin button.
  • Frame line — five options (Left, Right, Up, Down, None) that control the position of the coloured accent stripe.

The frame styling block is collapsed by default; click the ▸ button to expand it.

Position (X, Y) and Size (W, H)

The exact world‑space coordinates and dimensions. All four fields are editable — type a value and press Enter or click away to apply. Minimum size is W: 180, H: 130.

Notes

A multi‑line text area for director’s notes, camera descriptions, dialogue, etc. Notes are Inspector‑only metadata — they are not displayed inside the card body on the canvas. In View Mode, notes render as Markdown.

Code field (Codeblock only)

For Codeblock cards, a dedicated textarea appears in the Inspector. Write or paste code here; the card body updates with syntax‑highlighted preview in real time.

Video source section (Video Clip only)

For Video Clip cards, the Inspector shows a URL input and a file‑upload row. You can provide a YouTube/Vimeo link or choose a local video file. The two sources are exclusive — choosing one clears the other.

Delete Card

The red Delete Card button at the bottom of the Inspector removes the selected card and all its connections. If multiple cards are selected, it deletes all of them.

Edit & View Modes

Loom has two distinct modes accessed from the mode dropdown in the top bar. Your last‑used mode is remembered across sessions.

Edit Mode

Full editing is available: add, move, resize, and delete cards; manage blocks (for frames); draw and cut connections; manage groups; adjust the Inspector; undo and redo.

View Mode

Read‑only presentation mode. Editing controls are hidden from the UI:

  • New button, Clear button, and card toolbars are hidden.
  • Block controls, resize handles, delete buttons, and pin icons are hidden.
  • The Inspector fields become read‑only.
  • Undo and Redo are disabled.
  • Group action buttons are disabled.
  • Text blocks, titles, and notes render as Markdown — use this to show polished formatted content to collaborators.

Pan, zoom, card selection, and canvas navigation all remain fully functional in View Mode.

📋

Import a .json project — Loom automatically opens imported files in View Mode, making it easy to share a board for review without exposing editing tools.

Switching modes

Open the mode dropdown (top‑left of the top bar) and choose Edit Mode or View Mode. A dot indicator in the button turns teal in Edit Mode and amber in View Mode. A toast confirms the switch.

Frame Preview

In Edit Mode, each card can independently switch to a Markdown preview — letting you check rendered content without switching the entire board to View Mode.

Per‑card preview toggle

Hover over or select any card. An eye icon appears in the top‑right corner of the header. Click it to toggle that card between edit view (raw text) and preview (rendered Markdown). The toggle state persists while you’re in the same session.

When a card is in preview mode:

  • The card toolbar (for frames) and resize handle are hidden.
  • Block drag and delete controls are hidden.
  • Title, text blocks, and notes all render as Markdown.

Click the eye icon again to restore the card to its normal editable state.

Toggle all previews

Press Ctrl + Shift + P to toggle preview mode on or off for all visible cards at once. A toast confirms the action.

💡

Per‑card previews are session‑only — they are not saved to the project file and reset on reload. Use View Mode for permanent Markdown rendering in exports.

Undo & Redo

Loom tracks your full editing history in memory. Undo and Redo buttons sit in the top bar and are available by keyboard shortcut in Edit Mode.

Shortcuts

Keys Action
Ctrl + Z Undo
Ctrl + Y Redo
Ctrl + Shift + Z Redo (alternate)

What is and isn’t tracked

The history system takes a snapshot of the entire board state after each meaningful action:

  • Tracked: adding/deleting cards, moving, resizing, changing colours, adding/removing blocks, drawing/cutting connections, frame‑line changes, clearing the board, reordering blocks, creating/deleting/renaming/reordering groups, toggling group borders, hiding/showing groups, assigning cards to groups.
  • Not tracked: camera position (pan/zoom), panel widths, group collapse state, per‑card preview state — these are intentionally preserved across undo/redo so the viewport and UI don’t jump.

Debounced text edits

Typing in title, notes, group name, or text block fields doesn’t create a new history entry on every keystroke. Changes are batched and committed after a 700 ms pause. If you delete a card immediately after typing, Loom flushes the pending text snapshot first so the type and delete are two separate undo steps.

History depth

Up to 60 history states are kept. Older states are discarded when the limit is reached.

⚠️

History lives in memory only and is lost when you close or refresh the tab. For long sessions, export a .json project as a manual checkpoint.

Import & Export

Loom can save your work as a portable JSON project file or render a flat PNG image of the complete board.

Export → Project (.json)

Downloads the complete board state as a .json file. Contains:

  • All cards — positions, sizes, titles, colours, frame‑line settings, block content (for frames), code (for codeblocks), video URLs/data (for videoclips), and group assignments.
  • All connections between cards and their layer settings.
  • All groups — names, collapsed state, hidden state, border state, and sort order.
  • The current camera position, zoom level, panel layout widths, and project name.

Export → Storyboard (.png)

Renders a flat PNG image of the board. Only visible cards are included (hidden‑group cards are excluded). The export:

  • Automatically fits all visible cards with a consistent margin.
  • Includes visible connection strings and active group border highlights.
  • Hides editing chrome (toolbar buttons, resize handles, pin icons).
  • Uses the dark #1a1d24 void background.

Rasterised using html2canvas.

Import

Click Import in the top bar and pick a .json file previously exported from Loom. Importing replaces the current board entirely. The app:

  • Switches to View Mode automatically after import.
  • Restores group hidden and border states from the file.
  • Resets the undo/redo history and records the imported state as the starting point.
  • Runs Zoom to Fit to bring all visible cards into view.
⚠️

Importing overwrites your current board and cannot be undone via Ctrl+Z. Export your current project first if you want to keep it.
